# 📚 BookNook - Online Book Store

A lightweight e-commerce static web application for browsing and purchasing books.

## ✨ Features
- **Dynamic Search & Filtering**: Real-time filtering by book title, author, or category.
- **Interactive Shopping Cart**: Add items, view total, and save state using `localStorage`.
- **Responsive Design**: Clean UI powered by modern CSS Grid and Flexbox.

## 🚀 Setup
1. Open `index.html` in your browser.
2. Browse, filter, and add books to your shopping cart!
